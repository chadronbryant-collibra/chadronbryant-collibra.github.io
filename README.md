# Work Memory pages

This repository publishes a small static site that introduces Work Memory in
plain language. The page explains five jobs for keeping work easy to resume,
trust, reuse, and find, while pointing readers back to the source instead of
publishing live records.

## Read the pages

- [Open Work Memory](https://chadronbryant-collibra.github.io/collibra-workspace/)
- [Open the site root](https://chadronbryant-collibra.github.io/), which
  redirects to Work Memory

## How this repository is used

GitHub Pages serves the static HTML and CSS in this repository. The published
site files are maintained through their owning publication process. Update the
source there, validate the result, and then publish the reviewed static files
here rather than editing the generated page or styles directly.

The site is an orientation page. It contains no live records and does not
connect to a memory service.
