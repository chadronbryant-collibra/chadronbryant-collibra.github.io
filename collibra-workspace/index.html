COLLIBRA / WORK MEMORY

Keep the work worth keeping.

A simple way to know what just arrived, what needs attention, what happened, what is reusable, and where to find it again.

Explore the five jobs Put it to work
THE PROMISE

Less reconstructing. More continuing.

Work Memory does not replace the source. It helps people return to the source with the right context.

FIVE JOBS / PLAIN LANGUAGE

Start with the question you are asking.

Each kind of work has one clear home. The names describe what the information helps you do.

01
CAPTURE

What just arrived?

New material waits here while you decide whether it is useful, accurate, and worth keeping.

Use it for: notes, requests, observations, ideas, and evidence to review.

02
CURRENT

What needs attention now?

Active work stays visible so the next person—or future you—can continue without reconstructing the whole story.

Use it for: priorities, next steps, owners, blockers, and decisions in motion.

03
HISTORY

What happened, and why?

Durable context explains the decision and keeps the source trail intact.

Use it for: decisions, changes, outcomes, and the evidence that supports them.

04
KNOWLEDGE

What should we reuse?

Useful understanding becomes guidance people can apply without replaying every prior conversation.

Use it for: playbooks, definitions, patterns, lessons, and trusted references.

05
RECALL

How do I find it?

Search and useful views point back to the right source without becoming another copy of it.

Use it for: search, links, indexes, and views that help you return quickly.

HOW THE WORK MOVES

Review it before it becomes reusable.

New information does not become trusted guidance just because it was saved.

  1. 1Something arrives

    Capture it with enough source context to review.

  2. 2Someone decides

    Move active work into Current and make the next action clear.

  3. 3The work changes

    Keep the durable decision and its reason in History.

  4. 4The lesson earns reuse

    Turn the stable understanding into Knowledge.

  5. 5People find it again

    Recall points to the source and makes the next return faster.

USE IT TODAY

Ask one question before you file the work.

“What will someone need this for next?” The answer usually tells you where it belongs.

WHEN WORK STARTS

Make the next move visible.

Keep the owner, next action, blocker, and decision in one current view.

WHEN WORK ENDS

Keep the reason, not the noise.

Preserve the decision and source trail. Leave raw conversation behind unless it is itself the governed source.

WHEN WORK REPEATS

Promote the useful lesson.

Turn a stable pattern into guidance, then link it back to the evidence that earned trust.
